Q1: Summarize and Illustrate Storage Hierarchy

Summary: Storage systems are organized in a hierarchy based on speed, cost, and volatility. The higher levels (registers, cache) are faster, more expensive, and volatile. Lower levels (disks) are slower, cheaper, and non-volatile.

Q2: Importance of Interrupts

Interrupts allow hardware or software to signal the CPU that an event needs immediate attention. This makes the OS "interrupt-driven," allowing it to pause current tasks to handle critical events (like keyboard presses or errors) efficiently without constantly checking devices.

Q3: Client-Server vs. Peer-to-Peer

  • Client-Server: Centralized. Strict distinction between the machine requesting services (Client) and the machine providing them (Server).
  • Peer-to-Peer (P2P): Decentralized. No dedicated server. Every node is a "peer" and can act as both a client and a server simultaneously.

Q4: System Calls for File Management

  • CreateFile() / open()
  • ReadFile() / read()
  • WriteFile() / write()
  • CloseHandle() / close()
  • DeleteFile() / unlink()

Q2: Importance of Timesharing

Timesharing (multitasking) is vital for interactive computing. It switches the CPU between jobs so frequently that users can interact with each program while it runs. It ensures response times are short (< 1 second).

Q3: Virtualization vs. Cloud Computing

  • Virtualization: The technology that abstracts hardware to run multiple Guest OSes on a single Host OS (e.g., VMware).
  • Cloud Computing: The delivery model of computing, storage, and apps as a service over the Internet (e.g., AWS). It relies on virtualization.

  • MapViewOfFile() / mmap()

Q2: Importance of Multiprocessors

They provide Increased Throughput (more work in less time), Economy of Scale (cheaper than multiple machines sharing peripherals), and Increased Reliability (graceful degradation if one CPU fails).

Q3: SaaS vs. PaaS

  • SaaS (Software as a Service): Software available via Internet (e.g., Word, Gmail). You just use the app.
  • PaaS (Platform as a Service): Software stack ready for development via Internet (e.g., database server). You build apps on top of it.
